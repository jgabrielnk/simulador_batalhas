# Simulador de Batalhas

Este repositório contém o desenvolvimento de um **simulador de batalhas** implementado com as bibliotecas **Pygame** e **Tkinter**.

- A interface gráfica de configuração foi construída com **Tkinter**.
- A simulação e a lógica de batalha foram implementadas com **Pygame**.

> 💡 Todo o código foi gerado pelo modelo `gemini-2.5-pro-preview-03-25` por meio de **Vibe Coding**.
